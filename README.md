# POKEDEX

## About The Project

A mobile refresher project using React Native with Expo, per the original project description: a Pokedex application. Built with Expo SDK 52, file-based routing via expo-router, and data fetching with TanStack Query.

### Built With

- React Native
- Expo (SDK 52)
- expo-router
- TanStack Query
- TypeScript

## Getting Started

### Prerequisites

- Node.js and npm
- For device testing: Expo Go, an Android emulator, or an iOS simulator

### Installation

```sh
npm install
```

### Running

```sh
npx expo start
```

From the Expo CLI output you can open the app in a development build, an Android emulator, an iOS simulator, or Expo Go. `npm run android`, `npm run ios`, and `npm run web` start directly on a specific target.

### Tests

```sh
npm test
```

Tests run with Jest (jest-expo preset).
